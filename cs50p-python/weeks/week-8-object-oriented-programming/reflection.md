# Reflection

## What I learned

- I learned how to create classes to model real-world objects.
- I learned how to define instance methods and use the `self` parameter.
- I learned how constructors (`__init__`) initialize objects with attributes.
- I learned the difference between class design and simply writing functions.
- I learned how to use properties with `@property` and setter methods to validate data.
- I learned how encapsulation helps keep objects in a valid state.

## What confused me

- I was initially confused about when to use a class instead of a function.
- I found the purpose of `self` a little difficult to understand at first.
- I needed more practice understanding how properties differ from regular attributes.
- I sometimes mixed up instance attributes and class attributes.

## Mistakes I made

- I forgot to include `self` as the first parameter in instance methods.
- I accessed attributes directly instead of using properties when validation was needed.
- I forgot to initialize some attributes inside `__init__`.
- I created classes that were more complicated than necessary.

## Next action

- Practice writing small classes from scratch.
- Complete the Week 8 problem set without looking at solutions.
- Use properties and setters in future projects to reinforce encapsulation.
- Review object-oriented design principles by refactoring previous programs into classes.
